## Overview

VirtualOS (VOS) is an experimental operating system simulator created to explore how operating systems and desktop environments work.

Instead of replacing existing operating systems, VOS focuses on simulating important concepts in a controlled environment.

The project is built from scratch to understand:

- How desktops work
- How applications are managed
- How filesystems operate
- How terminals communicate with systems
- How different OS components interact


## Current Features

- 🖥️ Custom Desktop Environment
- 🪟 Window Management System
- 📂 Virtual File System
- ⌨️ Custom Terminal Architecture
- ⚙️ System Services
- 🎨 Themes and Customization
- 📦 Application Framework
- 🔧 Modular Project Architecture


## Technologies

- Python
- Object-Oriented Programming
- Git
- Linux Development Environment


> VOS is my learning platform for understanding system design, software architecture, and operating system concepts.

# 🌌 Project Hollow

### *Future Computing Environment Concept*


Project Hollow is the next major idea inspired by the lessons learned while developing VOS.

While VOS focuses on simulation and learning, Project Hollow explores a more advanced computing environment built around isolation, customization, and developer workflows.


## Core Idea

Project Hollow aims to create a unified experience where users can access different computing environments through one custom interface.


### 🔵 Developer Environment

A workspace designed for:

- Programming
- Engineering projects
- Development tools
- Software creation


### 🔴 Sandbox Environment

An isolated environment designed for:

- Security testing
- Experimentation
- Learning
- Safe software testing


### 🟣 Hollow Core

The main experience:

- Custom desktop
- File explorer
- Terminal
- Settings
- Application management
- Environment control


## Future Goals

- Modern native desktop interface
- Environment management system
- Secure sandboxing
- Developer-focused workflows
- Application integration
- Custom user experience


> Project Hollow represents my long-term exploration into operating systems, virtualization, security, and modern computing environments.
